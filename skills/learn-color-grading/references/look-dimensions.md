# Look Dimensions

Use this list to compare the reference and the user's image systematically.

| Dimension | How to recognize it |
|---|---|
| Crop, format | Portrait/landscape orientation, placement of the subject, negative space |
| Global color temperature | Overall cool/warm |
| Overall brightness | Center of mass in the histogram |
| Tonal range | Distance between the brightest and darkest value |
| Black point | True black or lifted/matte |
| White point | Pure white or muted highlights |
| Global contrast | Slope of the midtones |
| Micro-contrast | Three-dimensional feel of surfaces and textures |
| Saturation and palette | Which colors dominate, how strong |
| Hue of individual areas | e.g. grass yellow-olive instead of lime green |
| Brightness of individual colors | e.g. dark grass |
| Shadow color/highlight color | Tinted shadows, warm highlights |
| Light direction | Brightening of the subject, darkened edges |
| Atmospheric depth | Contrast/saturation decreases with distance |(unsure)
| Glow/softness | Soft shimmer in the highlights |
| Sharpness | Edge contrast, crispness |
| Distracting elements | Bright spots, people, artifacts |
